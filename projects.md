### 💻 RISC-V ALU and Pipelined Processor Design
**May 2025**

Developed a complete RISC-V processor implementation from ALU design to multi-stage pipelining with comprehensive hazard handling.

**Key Features:**
- Implemented arithmetic and logic operations using RISC-V microarchitecture
- Built multi-stage pipelined RISC-V processor with hazard handling
